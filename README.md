# Rutina

Pelacak kebiasaan dan arus kas harian — PWA satu file bertema taman botani ("Evergreen"), berbahasa Indonesia, mobile-first. Versi terkini: **v3.04.1** (`APP_VERSION` di `public/rutina.html`).

## Arsitektur

Aplikasi berjalan sepenuhnya dari satu file **`public/rutina.html`** — layout, gaya, ikon, dan mesin data tertanam di dalamnya. Sisa repo hanya penunjang:

```text
public/
  rutina.html      Aplikasi (shell PWA satu file)
  lab.html         CSS Lab — kebun efek CSS (demo + kode, satu file)
  sw.js            Service worker — network-first utk shell & aset, offline-first
  manifest.json    Manifest PWA
  icons/           Ikon PWA (SVG + 192/512 + maskable + apple-touch)
  illustrations/   ilustrasi hero, scene & motif kartu yang dipakai shell
  data/            master-makanan-indonesia.json — master 179 item (sumber embed FOOD_DB)
  tree/            5 tahap pohon konsistensi (benih→tunas→muda→dewasa→berbunga)
  fonts/           Geist (2 file woff2)
  robots.txt
src/app/
  page.tsx         Route "/" — redirect ke shell (fallback: iframe inline-style)
  api/rutina/      Jembatan data (baca-tulis, idempoten)
  layout.tsx       Layout minimal (cangkang)
```

## CSS Lab — kebun efek CSS

**`public/lab.html`** adalah perpustakaan efek CSS murni satu file (tanpa build, tanpa dependensi) yang menyertai shell:

- **131 efek** dalam 13 kategori: Teks (23), Kartu (22), Layar (15), Tombol (13), Loader (11), Latar (10), Animasi (9), Input (7), Toggle (7), Media (4), Lencana (4), Daftar (3), Petunjuk (3).
- Setiap kartu adalah **demo hidup** — hover/klik/fokus langsung mencoba efeknya.
- Dialog kode menampilkan **CSS & HTML persis yang menjalankan demo** (disuntikkan runtime dari data yang sama), lengkap dengan penyorotan sintaks ringan dan tombol salin + toast.
- Pencarian instan (pintasan `/`), filter kategori berhitung, tema visual mengikuti sistem desain Evergreen (Geist, terra/sage/honey, bayangan berlapis).
- Semua efek murni CSS — JS hanya untuk kerangka halaman (render, filter, dialog, salin). `prefers-reduced-motion` dihormati.
- Pintu masuk dari aplikasi: item **"CSS Lab"** di sidebar (desktop) dan kartu **Ruang eksperimen** di tab Pengaturan; dari lab, tautan **"Buka Rutina"** kembali ke shell.
- Kode efek memakai awalan kelas `fx-` yang unik per efek — aman disalin-tempel ke proyek mana pun.

## Fitur utama

- **Ringkasan** — progres harian, tren, animasi pembuka "Tunas Pagi", kartu **Semangat Hari Ini** (kutipan harian yang menempel pada progres asli), kartu **Suara Identitas** (Atomic Habits), dan kartu **Arus Kas Hari Ini** (v2.44, v2.45 penuh ilustrasi): "hari ini habis Rp X" — jalur aliran proporsional sage/rose (label porsi %), tiga ubin berilustrasi (keranjang keluar · tabungan masuk · tunas net) dengan metera banding, bedeng pos teratas ber-bar warna kategori, dan daftar hari ini (baris drillable). Kartu **Check-in Harian** (v2.39): mood · energi · tidur — tersinkron ke tabel `DailyLog`, terlihat juga di detail hari.
- **Kebiasaan** — pelacakan harian, target kuantitatif, riwayat mingguan, plus mekanik Atomic Habits: nudge **Jangan Bolong Dua Kali** (kartu yang kemarin terlewat), **Versi 2 Menit** + **Susun Kebiasaan** (jangkar "setelah X, aku akan Y"; kolom `Habit.mini`/`Habit.afterId`), dan nudge **Goldilocks** (pekan sempurna → "naik kelas?"; pekan <50% → "perkecil takarannya?"). Hero pohon tahap benih/tunas membawa microcopy **Fase Akar** (Plato Potensi Tersembunyi). **Sunting kebiasaan** (v2.37): aksi drill mengubah nama/kategori/grup/jam/versi mini/jangkar/ilustrasi tanpa kehilangan riwayat (jurnal `habitMeta`; ikon tersimpan di kolom `emoji` sebagai id `ill-…`). **Taman kebiasaan** (v2.37): tiap kebiasaan tampil sebagai tanaman (benih → tunas → pohon muda → pohon dewasa → berbunga, dari total catatan) di strip yang menggulir — tinggi nama dikunci dua baris (v2.39) supaya label tahap rata antar kartu.
- **Keuangan** — transaksi + transfer antar-dompet, dompet, anggaran per kategori, peta panas pengeluaran; tiga anak tab (Analisa / Mutasi / Saldo Bank). Mutasi Transaksi (v2.43) membawa **total tiap tanggal** di kepala grup — net harian atau jumlah jenis terfilter, selalu cocok dengan baris yang tampak. **Transaksi berulang** (v2.37): pilih "Setiap bulan/minggu" saat mencatat — occurrence jatuh tempo dilahirkan otomatis dengan id deterministik (`rec-…`), hapus instance diingat per perangkat.
- **Kalender** — catatan hari & ritme pekan; **pembanding pekan** (v2.37: hari aktif · catatan · pengeluaran vs pekan lalu) di kartu Ritme Ringkasan, dan **laporan bulanan** (v2.37) yang mengikuti bulan yang dibuka: konsistensi, top-3 kategori, anggaran, refleksi suara identitas.
- **Wawasan** — pola, laporan, lencana.
- **CSS Lab** — kebun efek CSS satu file (`public/lab.html`): 131 efek murni dalam 13 kategori dengan demo hidup, kode siap salin, pencarian & filter; diakses dari sidebar / tab Pengaturan.
- **PWA** — pasang ke layar utama, offline-first.

## Menjalankan lokal

```bash
bun install   # atau: npm install
bun run dev   # buka http://localhost:3000
```

Opsional: salin `.env.example` → `.env`, isi `RUTINA_TURSO_URL` & `RUTINA_TURSO_TOKEN` untuk sinkronisasi Turso.

## Deploy

Vercel, branch `main` (lihat `vercel.json`). Set env `RUTINA_TURSO_URL` + `RUTINA_TURSO_TOKEN` di dashboard untuk data awan; tanpa itu API memakai SQLite lokal per-instance.

## Konvensi

- **Satu sumber versi**: `APP_VERSION` di `public/rutina.html` (tampil di kartu Ringkasan akun tab Pengaturan). Setiap perubahan perilaku menaikkan versi **dan** `STATIC_CACHE` di `sw.js` supaya klien lama segera diperbarui.
- Mobile-first (diuji di 390×844); semua animasi menghormati `prefers-reduced-motion`.
- Bahasa UI: Indonesia. Aset & konten visual digambar tangan, tanpa dependensi ikon eksternal.
- Riwayat perubahan detail ada di README ini; kepala `public/rutina.html` menyimpan arsip kendala satu-baris per versi (v2.66: narasi panjang dipangkas, sejarah lengkap tetap di git).
